# Sam的昆虫大作战 🐛⚔️

一个有趣的卡牌对战游戏，专为小朋友设计！

## 游戏特点

- 🎮 简单好玩的卡牌对战系统
- 🐛 包含真实的昆虫科普知识
- 👦 Sam的手工昆虫图片展示
- 🎨 精美的炉石传说风格UI
- ⚡ 有趣的战斗机制

## 昆虫英雄们

1. 🕷️ **巴西游走蛛** - 毒属性，必杀技：毒液注射
2. 🦗 **豆娘稚虫** - 水属性，必杀技：面具突袭  
3. 🦂 **避日蛛** - 力量属性，必杀技：大颚咬破

## 如何运行

```bash
# 安装依赖
npm install

# 开发模式
npm run dev

# 构建项目
npm run build

# 预览生产版本
npm run preview
```

## 使用的技术

- React + Vite
- Tailwind CSS
- JavaScript
